# CogniFlow v1.3.0 功能总结

## 🎉 本次更新亮点

### 1. URL链接管理系统 🔗
智能识别和管理URL链接,自动抓取网页内容并生成AI梗概

### 2. 主题页面二级导航 📑
新增标签和历史记录两个子页面,信息组织更清晰

## ✨ 详细功能说明

### URL链接管理

#### 自动识别
- 输入URL时自动检测
- 支持http和https协议
- 智能判断是否为URL类型

#### 内容抓取
- 自动访问网站
- 提取网站标题
- 提取缩略图(og:image, twitter:image)
- 提取正文内容

#### AI梗概生成
- 使用Gemini AI
- 生成100-150字中文梗概
- 准确概括网站主要内容

#### 链接库管理
- 专属"链接库"Tab页面
- URLCard卡片展示
- 显示标题、缩略图、梗概、URL
- 支持打开链接和删除操作
- 支持搜索链接内容

### 主题页面优化

#### 二级Tab导航
```
主题 Tab
├── 标签 Sub-Tab
│   ├── 标签统计列表
│   └── 标签详情(点击后)
└── 历史记录 Sub-Tab
    └── 全部条目(时间倒序)
```

#### 标签页面
- 显示所有标签统计
- 卡片式布局
- 使用次数和最后使用时间
- 点击查看标签详情

#### 历史记录页面
- 显示所有条目
- 按创建时间倒序排列
- 支持所有类型(task/event/note/data/url)
- 快速浏览和管理

## 🎯 使用场景

### 场景1: 收藏文章
```
1. 复制文章URL
2. 粘贴到输入框
3. 系统自动抓取内容
4. 保存到链接库
5. 随时查看梗概
```

### 场景2: 整理资料
```
1. 收集多个技术文档链接
2. AI自动生成每个文档的梗概
3. 在链接库中统一管理
4. 需要时快速找到并打开
```

### 场景3: 回顾历史
```
1. 打开主题 → 历史记录
2. 按时间顺序查看所有条目
3. 回顾最近的工作和想法
4. 发现需要跟进的事项
```

### 场景4: 主题整理
```
1. 打开主题 → 标签
2. 查看标签使用统计
3. 点击标签查看相关内容
4. 整理和归档旧内容
```

## 💡 使用建议

### 最佳实践
1. **URL收藏**: 遇到好文章立即保存,AI梗概帮助快速回顾
2. **定期整理**: 每周查看历史记录,归档完成的事项
3. **标签管理**: 使用标签组织内容,便于查找
4. **搜索功能**: 善用搜索快速定位内容

### 注意事项
1. URL必须是完整的(包含http/https)
2. 某些网站可能无法抓取(需要登录、反爬虫)
3. AI梗概需要配置GEMINI_API_KEY
4. 网页抓取可能需要几秒钟
