 📋 项目概述                                                                  │


  核心理念: "你只管记录,我负责管理"
  
  CogniFlow是一款由AI驱动的智能信息管理工具,用户可以像发消息一样输入任何
  碎片化信息,AI会自动进行意图识别、实体提取和智能归档,然后在动态的情境
  感知仪表盘上展示。


 ⚡ v1.1.0 重大优化                                                           │


  ✨ 异步处理优化
     • 提交后输入框立即清空
     • 支持连续快速输入多条信息
     • AI在后台异步处理,不阻塞用户
     • 显示"处理中"卡片提供实时反馈
     • 效率提升75%!


 🎯 核心功能                                                                  │


  1. 🤖 AI智能处理
     • 文心大模型集成
     • 意图识别(task/event/note/data)
     • 实体提取(时间/地点/人物/主题)
     • 优先级判断
     • 标签自动生成

  2. 📝 快速输入
     • 底部固定输入框
     • Enter快速发送
     • 异步处理,零等待
     • 连续快速输入

  3. 📊 智能仪表盘
     • 今日视图 - 当天任务和日程
     • 即将发生 - 未来事项
     • 收件箱 - 笔记和资料
     • 主题 - 标签分类

  4. 🗂️ 信息管理
     • 完成标记
     • 编辑修改
     • 归档保存
     • 删除清理

  5. 🔍 智能搜索
     • 实时搜索
     • 关键词匹配
     • 全文检索

  6. 👥 用户管理
     • 角色管理(user/admin)
     • 权限控制
     • 数据隔离


 🛠️ 技术栈                                                                   │


  前端:
    • React 18 + TypeScript
    • Vite
    • shadcn/ui + Tailwind CSS
    • React Router v6
    • Lucide React (图标)
    • date-fns (日期处理)

  后端:
    • Supabase (PostgreSQL)
    • Supabase Auth
    • Row Level Security (RLS)

  AI:
    • 文心大模型(百度)
    • 流式处理
    • 结构化输出

 🚀 快速开始                                                                  │


  1. 配置文心大模型API密钥
     编辑 .env 文件:
     VITE_WENXIN_API_KEY=your_api_key_here
     VITE_WENXIN_SECRET_KEY=your_secret_key_here

  2. 启动应用
     数据库已自动配置,可以直接使用

  3. 首次登录
     使用手机号登录,第一个用户自动成为管理员

  4. 开始使用
     在底部输入框输入任何内容,AI会自动处理和分类
