## 🔍 功能1: 对话式查询

### 什么是对话式查询?

对话式查询让您可以用自然语言快速查找已有的任务、日程、笔记等,无需切换Tab页面。

### 如何使用?

#### 方法1: 使用特殊前缀

在输入框开头输入 `?` 或 `/q`,然后输入查询内容:

```
? 今天有什么事?
? 本周的会议
? 明天的任务
/q 标签:工作
```

#### 方法2: 直接输入查询语句

系统会自动识别包含查询关键词的输入:

```
查询今天的任务
查看下周的日程
搜索会议相关的内容
今天有什么安排
```

### 查询示例

#### 按时间查询
```
? 今天有什么事?          → 查询今天的所有事项
? 明天的任务            → 查询明天的任务
? 本周的会议            → 查询本周的日程
? 下周的安排            → 查询下周的事项
```

#### 按类型查询
```
? 查询所有任务          → 只显示任务类型
? 查看日程              → 只显示日程类型
? 我的笔记              → 只显示笔记类型
? 链接                  → 只显示URL类型
```

#### 按标签查询
```
? 标签:工作             → 查询带"工作"标签的事项
? 标签:个人             → 查询带"个人"标签的事项
```

#### 组合查询
```
? 今天的工作任务        → 今天 + 工作标签 + 任务类型
? 本周的重要会议        → 本周 + 会议 + 高优先级
```

### 查询结果

- 结果会在输入框上方以浮层形式展示
- 显示查询摘要和结果数量
- 可以直接在结果中操作(编辑、删除)
- 按 `ESC` 键或点击外部区域关闭浮层

### 提示

- ✅ 查询前缀必须在开头
- ✅ 支持中文自然语言
- ✅ 查询不会创建新条目
- ✅ 查询结果不会污染主视图

## ⚠️ 功能2: 冲突事项高亮

### 什么是冲突检测?

当您创建的日程与已有日程时间重叠时,系统会自动检测并用红色边框和警告图标提醒您。

### 如何工作?

#### 自动检测

系统会在以下情况自动检测冲突:
- 创建新的日程(Event类型)
- 编辑日程的时间
- 设置日程的开始和结束时间

#### 冲突判断

两个日程存在冲突的条件:
```
日程A的开始时间 < 日程B的结束时间
且
日程A的结束时间 > 日程B的开始时间
```

### 视觉提示

#### 红色边框
冲突的日程会显示醒目的红色左边框

#### 警告图标
标题旁边会显示红色的 ⚠️ 图标

#### Tooltip提示
鼠标悬停在警告图标上会显示:
```
⚠️ 此日程存在时间冲突
```

### 使用示例

#### 场景1: 发现冲突

```
步骤1: 已有日程
- 标题: 团队会议
- 时间: 今天 14:00 - 15:00

步骤2: 创建新日程
- 标题: 客户拜访
- 时间: 今天 14:30 - 15:30

步骤3: 系统检测
- 两个日程时间重叠
- 自动标记为冲突

步骤4: 视觉警告
- 两个日程都显示红色边框
- 都显示警告图标
- 鼠标悬停查看提示
```

#### 场景2: 解决冲突

```
方法1: 调整时间
1. 点击编辑其中一个日程
2. 修改开始或结束时间
3. 保存后冲突自动解除
4. 红色边框和图标消失

方法2: 删除日程
1. 删除其中一个日程
2. 冲突自动解除
```

### 提示

- ✅ 只对日程(Event)类型生效
- ✅ 必须设置开始和结束时间
- ✅ 自动检测,无需手动操作
- ✅ 冲突解除后自动恢复正常

## 📅 功能3: 时间字段增强

### 新增时间字段

v1.4.0为日程类型添加了精确的时间字段:

- **开始时间** (start_time): 日程开始的精确时间
- **结束时间** (end_time): 日程结束的精确时间

### 如何使用?

#### 创建日程时

在输入框输入包含时间的日程:
```
明天下午2点到3点开会
今晚6点到8点聚餐
下周一上午9点到10点面试
```

AI会自动识别并设置:
- `start_time`: 2025-10-28 14:00:00
- `end_time`: 2025-10-28 15:00:00

#### 编辑日程时

点击编辑按钮,可以手动调整:
- 开始时间
- 结束时间

### 显示效果

在ItemCard中会显示:
```
📅 14:00 - 15:00
```

### 提示

- ✅ 开始和结束时间必须同时设置
- ✅ 结束时间必须晚于开始时间
- ✅ 用于冲突检测
- ✅ 为日历视图做准备

## ❓ 常见问题

### Q1: 查询前缀必须在开头吗?

**A**: 是的,`?` 或 `/q` 必须在输入的最开头。

```
✅ 正确: ? 今天有什么事?
❌ 错误: 今天有什么事?
```

如果不想用前缀,可以直接输入包含查询关键词的语句:
```
✅ 正确: 查询今天的任务
✅ 正确: 今天有什么安排
```

### Q2: 为什么我的日程没有显示冲突?

**A**: 冲突检测需要满足以下条件:
1. 条目类型必须是"日程"(Event)
2. 必须设置开始时间(start_time)
3. 必须设置结束时间(end_time)
4. 两个日程的时间确实重叠

### Q3: 查询结果太多怎么办?

**A**: 可以使用更精确的查询:
```
模糊查询: ? 任务
精确查询: ? 今天的工作任务
```

### Q4: 可以查询已完成的事项吗?

**A**: 可以,查询会包含所有状态的事项。如果只想查询未完成的,可以在查询后手动筛选。

### Q5: 冲突检测会影响任务(Task)吗?

**A**: 不会,冲突检测只对日程(Event)类型生效。任务类型不会触发冲突检测。
