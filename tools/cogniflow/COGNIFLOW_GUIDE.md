# CogniFlow 智能流笔记 - 用户指南

## 📋 产品简介

CogniFlow是一款由AI驱动的智能信息管理工具,帮助您轻松管理日常工作和生活中的碎片化信息。

**核心理念**: 你只管记录,我负责管理

## ✨ 核心功能

### 1. 流式输入
- 在页面底部的输入框中,像发消息一样输入任何想法、任务或日程
- 支持Enter快速发送,Shift+Enter换行
- **异步处理**: 点击发送后输入框立即清空,可以继续输入下一条
- 显示"处理中"卡片,AI在后台异步处理
- 处理完成后自动更新为真实内容
- **优势**: 可以连续快速输入多条信息,无需等待,大大提升效率!

### 2. 智能分类
AI会自动将您的输入分为四种类型:
- **任务(Task)**: 需要完成的待办事项
- **日程(Event)**: 有明确时间的活动安排
- **笔记(Note)**: 灵感、想法、备忘
- **资料(Data)**: 需要保存的信息和数据

### 3. 智能仪表盘
四个视图帮您高效管理信息:

#### 今日视图 📅
- 显示今天需要完成的任务和日程
- 支持优先级排序
- 过期任务会有红色提醒

#### 即将发生视图 📆
- 显示未来的任务和日程
- 按时间顺序排列
- 提前规划您的时间

#### 收件箱视图 📥
- 存放没有明确时间的笔记和资料
- 灵感和想法的临时存储空间

#### 主题视图 🏷️
- AI自动提取的标签
- 点击标签查看相关内容
- 快速找到同类信息

### 4. 条目管理
每个信息卡片支持:
- ✅ 完成标记(任务和日程)
- ✏️ 编辑修改
- 📦 归档保存
- 🗑️ 删除清理

### 5. 智能搜索
- 顶部搜索框支持关键词搜索
- 实时显示搜索结果
- 快速定位所需信息

## 🎯 使用场景示例

### 场景1: 添加任务
**输入**: "明天下午3点前完成项目报告"
**AI识别**:
- 类型: 任务
- 标题: 完成项目报告
- 截止时间: 明天15:00
- 优先级: 中

### 场景2: 记录日程
**输入**: "周五晚上7点和张三吃饭,地点在市中心餐厅"
**AI识别**:
- 类型: 日程
- 标题: 和张三吃饭
- 时间: 周五19:00
- 地点: 市中心餐厅
- 标签: 张三, 聚餐

### 场景3: 保存灵感
**输入**: "产品改进想法:可以增加语音输入功能"
**AI识别**:
- 类型: 笔记
- 标题: 产品改进想法
- 描述: 可以增加语音输入功能
- 标签: 产品, 改进

### 场景4: 存储资料
**输入**: "公司WiFi密码是Company2024"
**AI识别**:
- 类型: 资料
- 标题: 公司WiFi密码
- 内容: Company2024
- 标签: WiFi, 密码

## 👤 用户角色

### 普通用户
- 管理个人的任务、日程、笔记和资料
- 只能查看和编辑自己的内容
- 数据完全隔离,保护隐私

### 管理员
- 拥有所有普通用户权限
- 可以访问管理面板
- 管理用户角色和权限
- 查看系统统计信息

## 🔐 隐私与安全

- 所有数据加密存储
- 用户数据完全隔离
- 支持手机号登录
- 行级安全策略(RLS)保护

## 💡 使用技巧

1. **快速输入**: 想到什么就输入什么,不用担心格式,AI会帮您整理
2. **善用标签**: AI自动生成的标签可以帮您快速关联相关信息
3. **定期归档**: 完成的任务和过期的日程可以归档,保持界面清爽
4. **优先级管理**: 重要任务会有红色边框标识,优先处理
5. **搜索功能**: 记不清具体内容时,用搜索快速定位

## 🚀 快速开始

1. 使用手机号登录
2. 在底部输入框输入您的第一条信息
3. 查看AI如何智能分类和整理
4. 在不同视图中查看您的信息
5. 开始享受高效的信息管理体验!

## 📞 配置说明

### 环境变量配置

在使用前,需要配置以下环境变量(`.env`文件):

```env
# 文心大模型API配置(必需)
VITE_WENXIN_API_KEY=your_api_key_here
VITE_WENXIN_SECRET_KEY=your_secret_key_here
```

**获取文心大模型API密钥**:
1. 访问百度智能云控制台: https://console.bce.baidu.com/
2. 开通文心一言服务
3. 创建应用获取API Key和Secret Key
4. 将密钥填入`.env`文件

### 首次登录

第一个注册的用户会自动成为管理员,后续注册的用户为普通用户。
