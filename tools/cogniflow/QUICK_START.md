# CogniFlow 快速启动指南

## 🚀 5分钟快速开始

### 步骤1: 配置文心大模型API

在`.env`文件中配置您的文心大模型API密钥:

```env
VITE_WENXIN_API_KEY=your_api_key_here
VITE_WENXIN_SECRET_KEY=your_secret_key_here
```

**如何获取API密钥?**

1. 访问百度智能云: https://console.bce.baidu.com/
2. 登录/注册账号
3. 开通"文心一言"服务
4. 创建应用,获取API Key和Secret Key
5. 将密钥复制到`.env`文件

### 步骤2: 启动应用

应用已经配置完成,可以直接使用!

数据库已自动配置:
- ✅ Supabase已连接
- ✅ 数据表已创建
- ✅ 安全策略已启用

### 步骤3: 首次登录

1. 打开应用
2. 使用手机号登录
3. **重要**: 第一个注册的用户会自动成为管理员!

### 步骤4: 开始使用

1. 在底部输入框输入任何内容,例如:
   - "明天下午3点开会"
   - "记得买牛奶"
   - "产品改进想法:增加语音输入"

2. AI会自动:
   - 识别类型(任务/日程/笔记/资料)
   - 提取时间、地点等信息
   - 生成标签
   - 归档到对应视图

3. 在不同视图查看您的信息:
   - 📅 今日: 今天的任务和日程
   - 📆 即将发生: 未来的安排
   - 📥 收件箱: 笔记和资料
   - 🏷️ 主题: 按标签浏览

## 🎯 使用示例

### 添加任务
```
输入: "周五前完成项目报告"
AI识别:
- 类型: 任务
- 标题: 完成项目报告
- 截止: 本周五
- 优先级: 中
```

### 记录日程
```
输入: "明天下午2点和客户开会,地点在会议室A"
AI识别:
- 类型: 日程
- 标题: 和客户开会
- 时间: 明天14:00
- 地点: 会议室A
```

### 保存笔记
```
输入: "灵感:可以增加语音输入功能"
AI识别:
- 类型: 笔记
- 标题: 灵感
- 内容: 可以增加语音输入功能
```

## 💡 使用技巧

1. **自然输入**: 像说话一样输入,AI会理解
2. **包含时间**: 提到时间会自动设置截止日期
3. **使用标签**: AI生成的标签帮助关联信息
4. **定期归档**: 保持界面清爽
5. **善用搜索**: 快速找到需要的信息

## ⚙️ 高级配置(可选)

### 修改登录方式
在`.env`中修改:
```env

```

### 自定义隐私政策
```env
VITE_PRIVACY_POLICY_URL=https://your-domain.com/privacy
VITE_USER_POLICY_URL=https://your-domain.com/terms
```

## 🔧 故障排查

### AI处理失败
- 检查文心API密钥是否正确
- 确认API账户有余额
- 查看浏览器控制台错误信息

### 登录问题
- 确认Supabase配置正确
- 检查网络连接
- 清除浏览器缓存重试

### 数据不显示
- 刷新页面
- 检查是否登录
- 确认数据库连接正常
