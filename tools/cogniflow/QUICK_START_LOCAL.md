## 🎯 启动步骤

### 1. 重启开发服务器

如果服务器正在运行，停止它（Ctrl+C）然后重新启动：

```bash
npm run dev
# 或
pnpm run dev
# 或
yarn dev
```

### 2. 打开浏览器

访问 `http://localhost:5173`（或显示的端口）

### 3. 首次使用

应用会自动：
- 初始化 IndexedDB 数据库
- 创建默认用户
- 准备就绪！

## 💾 数据备份

### 导出数据
1. 点击 Header 右上角的 📥 图标
2. 自动下载 `cogniflow-backup-YYYY-MM-DD.json`
3. 妥善保管此文件

### 导入数据
1. 点击 Header 右上角的 📤 图标
2. 选择之前导出的 JSON 文件
3. 确认导入，页面会自动刷新

## 🐛 常见问题

### Q1: TypeScript 编译错误
**症状**: 显示"找不到模块"错误

**解决**:
```bash
# 1. 停止开发服务器
Ctrl+C

# 2. 删除缓存
rm -rf node_modules/.vite

# 3. 重新启动
npm run dev
```

### Q2: 数据没有保存
**症状**: 刷新页面后数据消失

**检查**:
1. 是否在隐私/无痕模式？
2. 是否允许浏览器存储数据？
3. 查看 Console 是否有错误

**解决**:
- 退出隐私模式
- 检查浏览器设置允许本地存储
- 查看错误日志

### Q3: AI 功能不工作
**症状**: 文本处理失败

**检查**:
- GLM API Key 是否配置正确？
- 网络连接是否正常？
- API 配额是否用完？

**解决**:
```env
# 检查 .env 文件
VITE_GLM_API_KEY=your_real_api_key
```

### Q4: 导入数据失败
**症状**: 导入 JSON 文件时报错

**检查**:
- JSON 格式是否正确？
- 文件是否完整？

**解决**:
- 使用 JSON 验证工具检查格式
- 尝试重新导出生成新备份

## 📊 性能优化
