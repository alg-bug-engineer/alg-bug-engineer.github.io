  用户反馈: 输入"今晚六点开会"这样的今日事项,在今日面板没有呈现



  原有逻辑的问题:
  
  ❌ 今日视图只查询有截止日期(due_date)的条目
  ❌ 如果AI没能识别时间,due_date为null
  ❌ 导致条目无处显示,用户找不到自己的输入
  ❌ 收件箱只显示note和data,不包含task和event

 解决方案


  1. 今日视图优化 - 现在包含三类条目:
  
     类型1: 今天有截止日期的任务和事件
     ┌─────────────────────────────────────────┐
     │ ✅ 今晚六点开会 (AI识别成功)            │
     │    due_date: 2025-10-27 18:00          │
     │    显示在今日视图                       │
     └─────────────────────────────────────────┘
     
     类型2: 今天创建但没有截止日期的任务和事件
     ┌─────────────────────────────────────────┐
     │ ✅ 今晚六点开会 (AI未识别时间)          │
     │    due_date: null                      │
     │    created_at: 今天                    │
     │    仍然显示在今日视图!                  │
     └─────────────────────────────────────────┘
     
     类型3: 过期但未完成的任务
     ┌─────────────────────────────────────────┐
     │ ⚠️ 完成月度报告 (昨天的任务)            │
     │    due_date: 2025-10-26               │
     │    status: pending                    │
     │    继续显示提醒用户                     │
     └─────────────────────────────────────────┘

  2. 收件箱优化 - 现在包含两类条目:
  
     类型1: 笔记和资料 (原有功能)
     ┌─────────────────────────────────────────┐
     │ 📝 记录一个想法                         │
     │    type: note                          │
     └─────────────────────────────────────────┘
     
     类型2: 没有截止日期的任务和事件 (新增)
     ┌─────────────────────────────────────────┐
     │ 📅 今晚六点开会 (AI未识别时间)          │
     │    type: event                         │
     │    due_date: null                      │
     │    可以在这里补充时间信息                │
     └─────────────────────────────────────────┘



  场景1: AI成功识别时间
  ────────────────────────────────────────────────────────
  用户输入: "今晚六点开会"
  
  AI处理:
  {
    "type": "event",
    "title": "开会",
    "due_date": "2025-10-27T18:00:00.000Z"
  }
  
  显示位置:
  ✅ 今日视图 (类型1: 今天有截止日期)
  ❌ 即将发生视图 (不是明天及以后)
  ❌ 收件箱 (有截止日期)

  场景2: AI未能识别时间
  ────────────────────────────────────────────────────────
  用户输入: "今晚六点开会"
  
  AI处理:
  {
    "type": "event",
    "title": "今晚六点开会",
    "due_date": null
  }
  
  显示位置:
  ✅ 今日视图 (类型2: 今天创建无截止日期)
  ❌ 即将发生视图 (没有截止日期)
  ✅ 收件箱 (类型2: 无截止日期的event)
  
  用户操作:
  → 在今日视图或收件箱中看到这条记录
  → 点击编辑,手动设置时间为18:00
  → 设置后,从收件箱消失,只在今日视图显示

  场景3: 明天的事项
  ────────────────────────────────────────────────────────
  用户输入: "明天下午三点面试"
  
  AI处理:
  {
    "type": "event",
    "title": "面试",
    "due_date": "2025-10-28T15:00:00.000Z"
  }
  
  显示位置:
  ❌ 今日视图 (不是今天)
  ✅ 即将发生视图 (明天的事件)
  ❌ 收件箱 (有截止日期)

  场景4: 过期未完成的任务
  ────────────────────────────────────────────────────────
  数据库记录:
  {
    "type": "task",
    "title": "完成月度报告",
    "due_date": "2025-10-26T23:59:59.000Z",  // 昨天
    "status": "pending"                       // 未完成
  }
  
  显示位置:
  ✅ 今日视图 (类型3: 过期未完成)
  ❌ 即将发生视图 (已经过期)
  ❌ 收件箱 (有截止日期)
  
  视觉提示:
  → 红色边框 (过期提醒)
  → "已过期"标签

  场景5: 记录笔记
  ────────────────────────────────────────────────────────
  用户输入: "记录一个想法:可以做一个时间管理工具"
  
  AI处理:
  {
    "type": "note",
    "title": "可以做一个时间管理工具",
    "due_date": null
  }
  
  显示位置:
  ❌ 今日视图 (不是task或event)
  ❌ 即将发生视图 (不是task或event)
  ✅ 收件箱 (类型1: note类型)

  场景6: 无明确时间的任务
  ────────────────────────────────────────────────────────
  用户输入: "有空的时候整理书架"
  
  AI处理:
  {
    "type": "task",
    "title": "整理书架",
    "due_date": null
  }
  
  显示位置:
  ✅ 今日视图 (类型2: 今天创建无截止日期)
  ❌ 即将发生视图 (没有截止日期)
  ✅ 收件箱 (类型2: 无截止日期的task)
  
  说明:
  → 同时出现在今日视图和收件箱
  → 今日视图: 提醒今天创建了这个任务
  → 收件箱: 作为待处理事项保存

  1. 多查询合并
     • 今日视图执行三个独立查询
     • 使用Promise.all并发执行
     • 合并结果并去重

  2. 数据去重
     • 使用Map基于id去重
     • 确保同一条目不重复显示

  3. 错误处理
     • 每个查询独立错误处理
     • 部分查询失败不影响其他查询
     • 详细的错误日志

  4. 排序逻辑
     • 今日视图: 按due_date升序
     • 即将发生: 按due_date升序
     • 收件箱: 按created_at降序



  ✅ 解决了"今晚六点开会"不显示的问题
     → 即使AI未识别时间,今天创建的条目仍会显示

     → 过期但未完成的任务继续显示在今日视图
